Conectar Google Calendar

Autoriza el acceso a los eventos de tu calendario principal.
Para activar la sincronización, primero configura el ID de cliente de Google en esta sección.
La aplicación solo solicita permiso para consultar y administrar eventos de Google Calendar. El token de acceso se mantiene en memoria y no se guarda en el almacenamiento local.

Cómo activar la conexión

  1. Abre Google Cloud Console e inicia sesión con tu cuenta.
  2. Crea un proyecto y, en APIs y servicios → Biblioteca, habilita Google Calendar API.
  3. Configura la pantalla de consentimiento OAuth. Si está en modo de prueba, agrega tu correo como usuario de prueba.
  4. En Credenciales → Crear credenciales → ID de cliente OAuth, selecciona Aplicación web.
  5. En Orígenes autorizados de JavaScript, agrega el dominio HTTPS donde se publicará esta aplicación (solo el dominio, sin ruta).
  6. Copia el ID de cliente que termina en .apps.googleusercontent.com, pégalo arriba y pulsa Guardar ID.
  7. Pulsa Conectar con Google y acepta los permisos.
No pegues aquí una contraseña ni el secreto de cliente. Esta aplicación necesita únicamente el ID de cliente OAuth. La conexión no funcionará abriendo el archivo directamente desde el teléfono: debe estar publicado en un sitio HTTPS.
